# 基于 Dify 的电商智能客服系统

## 项目简介

基于 Dify 低代码平台搭建的电商智能客服工作流，实现情绪识别、意图识别、问题分类路由、多知识库 RAG 检索、多轮对话记忆等功能，并部署至阿里云服务器实现公网可访问。

## 技术架构

```
用户消息
    ↓
情绪识别（愤怒→直接转人工）
    ↓
意图识别
    ↓
4分类路由：售后 / 物流 / 商品 / 其他
    ↓
对应知识库 RAG 检索（BGE-Embedding + BGE-Rerank，TopK=3）
    ↓
大模型生成回答
```

## 核心功能

### 1. 工作流编排
- 设计情绪识别→意图识别→4分类路由的完整对话流程
- 愤怒用户自动转人工，提升客服效率
- 支持多轮对话上下文理解

### 2. RAG 检索
- 构建 3 个独立知识库：售后政策、物流说明、商品信息
- 采用 BGE-Embedding + BGE-Rerank 两段式检索
- TopK=3 精准召回相关片段

### 3. 多轮对话
- 使用会话变量（Session Variable）记录上下文
- 支持"那运费呢"等指代性问题的上下文理解

### 4. 技术难点解决
- 针对 DeepSeek 思考模型输出 `<think>` 标签干扰结构化输出的问题
- 通过代码节点提取最终结果，保证条件分支判断准确率 100%

### 5. 云端部署
- 阿里云轻量应用服务器，Dify 应用镜像一键部署
- 配置通义千问 + DeepSeek + 硅基流动多模型供应商
- 公网可访问演示

## 如何导出工作流

1. 登录 Dify 平台，进入该应用
2. 点击右上角「...」→「导出 DSL」
3. 将导出的 YAML/JSON 文件保存为 `workflow_export.yaml` 放在本目录

> 本目录下的 `workflow_export.yaml` 为**工作流结构示例**（按本文档描述的流程搭建），
> 用于展示项目设计。真实可运行版本请按上述步骤从你的 Dify 平台导出后覆盖。
